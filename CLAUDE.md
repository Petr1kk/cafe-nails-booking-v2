## Правила проекта
- Секреты (пароль админки, токен Telegram-бота) — только в Script Properties Google. В код, чат, GitHub — никогда. `docs/config.js` содержит только публичный `API_URL`.
- После правки `apps-script/Core.gs` копировать в `docs/core.js` (`cmp` должен молчать). Запустить `tests/index.html` (`python -m http.server`, вкладка `PASS N`).
- Код сервера после правок нужно заново развернуть («Новая версия»), иначе `/exec` отдаёт старое.
- Не публиковать на GitHub / не создавать репозиторий без слова владельца.
