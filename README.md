# Запис до майстра — версія 2 (з адмін-панеллю)

Учебный проект для портфолио (вымышленный салон). Версия 1 (`../nail-salon-v1/`, репозиторий `cafe-nails-booking`) не тронута.
Что нового: поток «**послуги → майстер → час → дані**» (сначала услуги, затем мастера, которые их делают; стиль скандинавский, `docs/site.css`), карточки мастеров с фото и ближайшим временем, услуги по категориям (без поиска — он не нужен),
и **админ-панель менеджера** — мастеров, услуги и записи правят на сайте, а не в Google Таблице.

## Как устроено

```
 Клиент (index.html)          Менеджер (admin.html)
        │  GET/POST                │  POST + токен сессии
        └────────────┬─────────────┘
              Apps Script (Code.gs + Core.gs)  ← «кухня»
                 │        │         │        │
          Календари   Таблица    Gmail     Google Диск
         (занятость)  (профили,  (письма)  (фото мастеров)
                       услуги, записи)
```

- **Core.gs** — «мозг» без Google: расчёт свободного времени, проверка данных. Копия лежит на сайте как `docs/core.js` (после правки Core.gs копировать!). Тесты: `tests/index.html` → заголовок вкладки `PASS N`.
- **Правда о занятом времени** — календари мастеров. Таблица — «база» профилей, услуг и записей.
- **Демо-режим**: если в `docs/config.js` пусто `API_URL`, сайт и админка работают в браузере без Google (`docs/demo.js`, данные в localStorage, пароль админки `demo`).
- **Логотип**: файл `docs/logo.svg` (сейчас заглушка «Nail Studio»). Свой логотип — положить файл с тем же именем `logo.svg` (лучше квадратный). Если логотип PNG — положить `logo.png` и в `docs/index.html` в блоке `class="brand"` поменять `src="logo.svg"` на `src="logo.png"`. Там же, рядом, текст «Nail Studio» — название салона.

## Что умеет админка
- Вход по паролю (пароль хранится в Script Properties только как «отпечаток» с солью; на сайте и в таблице его нет). 5 неудач подряд — блок на 15 минут. Сессия 6 часов.
- Мастер: имя, спеціальність, дни/часы/обед, **почта, телефон, Telegram**, **фото**, какие услуги делает, вкл/выкл. Мастеров не удаляем, а отключаем (история записей остаётся).
- Услуги: название, категория, время, цена, показать/скрыть.
- Записи: список будущих, отмена менеджером (клиенту уходит письмо, событие удаляется из календаря).
- Почта мастера: есть → при записи он получает **приглашение в Google Календарь** (событие появляется у него в календаре, письмо приходит от Google). Нет → ничего не шлём. Меняется/убирается → сервер «переподписывает» будущие события календаря мастера.
- Фото: браузер сжимает до 600×600 JPEG, сервер кладёт в папку «Фото майстрів» на Google Диске и сохраняет ссылку.
- Менеджеру **не нужно вручную выдавать доступы** к календарям: календарь создаёт сам скрипт, мастер получает приглашения по почте.

## Развёртывание (когда будем подключать настоящий Google)
1. Новая Google Таблица → «Розширення → Apps Script».
2. В проекте два файла: `Core.gs` и `Code.gs` (содержимое из папки `apps-script/`); в «Налаштування проєкту» включить показ `appsscript.json` и вставить его содержимое (там права на Диск).
3. Выбрать функцию `setup` → «Выполнить», дать права. В журнале выполнения появится **пароль админки** (один раз; сохранить в менеджер паролей). Забыли — запустить `resetAdminPassword`.
4. «Начать развёртывание → Веб-приложение»: выполнять от моего имени, доступ — все. Скопировать адрес `/exec` в `docs/config.js` → `API_URL`.
5. В листе «Налаштування» заполнить «Пошта власника» и «Адреса сайту».
6. После любой правки кода: «Управление развёртываниями → карандаш → Новая версия → Развернуть».

## Риски и честные ограничения
- Пароль админки — единственная защита панели. Хороший пароль, не светить журнал выполнения. Блок после 5 неудач общий на всех (можно «заблокировать» вход спамом — но данные не откроются).
- Письма: лимит Gmail ~100/день на бесплатном аккаунте.
- Приглашения в календарь работают для любой почты, но у не-Google почты это письмо-календарное приглашение (ICS).
- Telegram-бот (уведомления) — **этап 2**, пока в профиле хранится только username/телефон. Бот не может написать по username/номеру: мастер должен один раз нажать Start у бота по личной ссылке.
- Сессионные токены лежат в кеше Google (до 6 ч) — после сброса кеша нужно войти снова.
